Theme note: Sass customization is available if the portal grows into a larger deployment. The steps are:
  1. Run npm install bootstrap sass
  2. Create custom.scss and import Bootstrap: @import "bootstrap/scss/bootstrap";
  3. Override variables before the import: $primary: #4a0080; $border-radius: 0.5rem;
  4. Compile: npx sass custom.scss custom.css
  5. Link custom.css instead of Bootstrap CDN

For this portal, the :root CSS variables at the top of this file override Bootstrap's default primary color and border radius.
