# Module1

A simple multi-page event portal built with HTML, CSS, and JavaScript.

## Files
- `index.html` — main portal page
- `bootstrop.html` — dashboard page
- `auth.html` — sign in / sign up page
- `help.html` — support page
- `style.css` — shared styling
- `script.js` — shared page behavior

## Run
Open `index.html` in a browser.
